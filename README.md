# BI Didático — instaladores para Windows

Baixe o arquivo `BI-Didatico-Setup-<versão>.exe` da [última release](https://github.com/Engenharia-Finder/finder-bi-didattico-releases/releases/latest) e execute. Não precisa de permissão de administrador nem de outros programas.

Na primeira abertura, informe os dados do banco do WordPress. O IP do computador precisa estar liberado no cPanel, em **MySQL Remoto**.

Depois de instalado, o programa verifica este repositório sempre que é aberto, avisa quando há uma versão nova e se atualiza sozinho.

Este repositório guarda apenas os instaladores; o código-fonte é privado.
